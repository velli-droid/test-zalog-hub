# Файлы караоке

Добавьте в эту папку файлы одной и той же версии песни «Дора — Втюрилась»:

- `dora-vtyurilas.mp3` — аудио;
- `dora-vtyurilas.lrc` — текст в UTF-8 с таймингами строк.

Формат LRC (ниже только пример формата, не текст песни):

```text
[00:05.00]Первая строка
[00:09.50]Вторая строка
[00:14.00]
```

Строка действует до следующей временной отметки. Пустая строка с таймингом убирает задачу на время инструментального фрагмента. Поддерживаются повторные тайминги одной строки и `[offset:500]` для смещения на 500 миллисекунд.

После добавления файлов нажмите «Начать караоке». Для другой версии или формата аудио измените пути в `src/config/karaoke.ts`. Файлы из `public` доступны от корня сайта, без `/public` в URL.
