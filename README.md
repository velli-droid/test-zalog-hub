# Тестовое задание ZalogHub

Список задач с режимом караоке на React + TypeScript, Vite и Zustand. Компоненты shadcn/ui находятся в `src/components/ui`: Button, Input, Checkbox, Tabs и Slider. Стили — Tailwind CSS и адаптивный CSS, иконки — Lucide, анимации — Motion.

## Демо

[Открыть приложение](https://nf6t2k.csb.app/)

## Запуск

Требуются Node.js 24 и npm. Откройте терминал в корне проекта и выполните:

```sh
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминал — обычно `http://localhost:5173`. Для остановки сервера нажмите `Ctrl+C`.

Задачи сохраняются в браузере; отдельный сервер или база данных не нужны.

## Время выполнения

Ориентировочные трудозатраты на реализацию и доработки — **2-3 часа**.

## Качество кода

```sh
npm run lint
npm run lint:fix
npm run format
npm run format:check
```

ESLint проверяет весь JavaScript и TypeScript, правила React Hooks и React Refresh. Prettier проверяет форматирование исходников, стилей, HTML, JSON, Markdown и конфигураций. Генерируемые файлы и lock-файл исключены из форматирования. Отступ — 4 пробела, без символов табуляции; настройки закреплены в `.editorconfig` и `.prettierrc.json`.

Состояние задач, операции и сохранение в localStorage находятся в Zustand-сторе `src/stores/task-store.ts`. Хук `useTasks` отвечает за фильтр, производные данные и состояния пустого списка; `useTaskForm` — за ввод, отправку формы и фокус.

## Сборка

```sh
npm run build
npm run preview
```

Сборка создаётся в папке `dist`. Команда `preview` запускает её локальный просмотр; адрес появится в терминале.

## Возможности

- Добавление задачи кнопкой или клавишей Enter; пустые строки не добавляются.
- Отметка выполнения, удаление и очистка выполненных задач.
- Фильтры: все, активные, выполненные.
- Счётчик задач и автоматическое сохранение в localStorage.
- Адаптивный интерфейс на русском языке и управление с клавиатуры.
- Режим караоке: активная строка песни появляется временной задачей и заменяется следующей.
- Предпросмотр следующей строки за 2 секунды до начала.
- Пауза, остановка, регулировка громкости и отключение звука.

## Караоке

Файлы песни находятся в `public/karaoke/dora-vtyurilas.mp3` и `public/karaoke/dora-vtyurilas.lrc`. Нажмите «Начать караоке», чтобы включить «Дора — Втюрилась». Первая строка появляется на 5,67 секунды; следующая показывается заранее и отличается от активной. Громкость регулируется ползунком, кнопка динамика отключает и включает звук.

Для замены записи используйте аудио и тайминги одной версии песни. Название, пути и время предпросмотра задаются в `src/config/karaoke.ts`; формат LRC описан в `public/karaoke/README.md`.

Пауза сохраняет текущую строку. Остановка и конец песни убирают её. Пустая строка с таймингом очищает задачу на время проигрыша. Караоке работает независимо от фильтров обычных задач, не меняет их счётчики и не сохраняет строки песни в localStorage.

Состояние сеанса находится в `src/stores/karaoke-store.ts`, управление аудио — в `src/hooks/use-karaoke.ts`, разбор таймингов — в `src/lib/karaoke.ts`.

Данные хранятся только в текущем браузере. При недоступном хранилище приложение сообщает об этом и продолжает работать до закрытия страницы.
